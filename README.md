# Helpful Skills

Reusable agent skills for developer workflows — from navigating breaking changes in development tools to running a screened, personalized job search.

## Available skills

| Skill | Purpose |
| --- | --- |
| [Xcode Device Hub](xcode-device-hub/README.md) | Handle the Xcode 26.x to 27.x Simulator transition, diagnose sandbox and automation failures, and verify apps with a simctl/XCTest fallback. |
| [Job Search Scout](job-search-scout/README.md) | Run a personalized job search across Indeed, Dice and Built-In from a profile (resume, target titles, workplace and pay rules), screen out disguised sales roles, staffing funnels and OTE-inflated pay, and check each employer's recent layoffs and reviews before ranking. |

Each folder is a self-contained skill. See its README for installation and its `SKILL.md` for agent instructions.

# Helpful Skills for Breaking Changes

Reusable agent skills for navigating breaking changes in development tools.

## Available skills

| Skill | Purpose |
| --- | --- |
| [Xcode Device Hub](xcode-device-hub/README.md) | Handle the Xcode 26.x to 27.x Simulator transition, diagnose sandbox and automation failures, and verify apps with a simctl/XCTest fallback. |

Each folder is a self-contained skill. See its README for installation and its `SKILL.md` for agent instructions.
